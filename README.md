# ROBOT-ARM-TORQUE — H2-X 오른팔 토크–각변위 (웹)

Unitree H2-X 전신이 서 있는 상태(골반 고정)에서 오른팔 7축을 슬라이더로 움직이고,
팔 자체 질량·손 하중(무게중심 오프셋 포함)을 바꾸면서 관절별 **감속기 출력축 토크–각변위**를 실시간으로 본다.
index.html을 연 화면이 곧 시뮬레이터 (GitHub Pages: main / root).

## 계산
- `dynamics.js` (외부 라이브러리 없음, 브라우저·Node 공용)
  - 링크 질량·무게중심·관성텐서 = URDF 원본. 골반 고정, 높이 1.0237 m(발바닥 z=0)
  - 역동역학 RNEA, 질량행렬 = 단위가속도 RNEA, 적분 1 ms
  - 구동: 속도·가속도 제한 궤적 → 피드포워드(실제 자세 · 기준 궤적의 역동역학 + 구동부 보상) + 관절별 PD
    (관성 스케일 D는 폐루프 고유값 λ = eig(D½M⁻¹D½) ≤ 3이 되게 축소 → 한 관절이 포화돼도 다른 관절이 떨지 않음)
  - 토크 한계 = URDF `effort` (구동 명령 클립), 가동범위 = 기계식 스토퍼(충격량)
- **구동부(액추에이터) 모델** — URDF에 없는 값이라 관절별 가정값, 화면 표에서 수정
  - 로터 반사관성 J = 로터관성 × 감속비² (기본 0.03 / 0.025×3 / 0.01×3 kg·m²)
  - 마찰 τf = b·ω + τc·tanh(ω / 0.02 rad/s) (기본 b 1/1/1/1/0.5/0.5/0.5 N·m·s/rad, τc 1/0.5/0.5/0.5/0.25/0.25/0.25 N·m)
  - 마찰은 암시적으로 적분(안정). [구동부 0] 버튼 = 강체 이상값
  - **그래프 토크 = 감속기 출력축 토크 = 구동토크 − J·q̈ − τf** (링크에 실제 전달되는 토크; 정지 시 마찰 0이면 구동토크와 같음)
- **충돌**
  - 모든 링크 메시를 k-means 구 735개로 근사(`tools/make_model.py`, 표면적 비례 개수)
  - 오른팔 7링크(+손 하중 구) ↔ 몸(몸통·골반·다리·머리·왼팔), 오른팔 자기충돌(인접 링크 제외)
  - 기준 자세에서 이미 겹치는 링크 쌍(어깨 관절부)과 몸통 구 중 오른어깨 관절 반경 13 cm 이내는 제외
  - 접촉은 비탄성 충격량(투영 가우스–자이델, 스토퍼와 함께 풂), 접촉력과 상대 링크를 화면에 표시
- **몸 자세**: 허리 yaw·roll·pitch, 머리 2축, 왼팔 7축을 슬라이더로 설정(정적 고정). 허리를 기울이면 오른팔 기준 중력 방향이 바뀜. 다리는 골반 고정이라 0 rad 표시만
- **제어 방식** (화면에서 전환)
  - 위치 제어: 기준 궤적 + 피드포워드 + 관절 PD (ωn 60 rad/s, 관절별 유효관성 스케일, λ ≤ 3)
  - 임피던스 제어: τ = 중력·코리올리 + Jᵀ[K·Δx + D·Δẋ] + 영공간 자세 유지(Knull). 손 기준점 = 손에 든 물체 무게중심 위치,
    목표 = 슬라이더 자세의 손 위치·방향, D = 2ζ√(K·Λ), Λ = (J M⁻¹ Jᵀ)⁻¹ 대각. 기본 K 300 N/m, Kr 10 N·m/rad, ζ 0.8
- **충격**: 손 기준점·손목·팔꿈치에 반-사인파 외력(최대 힘·지속시간·방향 지정, 충격량 2FT/π) → τext = Jpᵀ F
- **랜덤 자세**: 가동범위 안(양끝 8% 제외), 몸과 1 cm 이상 이격, 현재 하중으로 정지 토크 ≤ 한계 80%. 자동 반복 가능
- 팔 질량 변경: 7링크 질량·관성 ×k, 무게중심 유지. 손 하중: 손 링크(`right_wrist_yaw_link`)에 균질구(r 3 cm)로 강체 결합, 들 때 1초 램프 · 내려놓기 즉시

## 검증
`node dynamics_test.js` — 모두 자동 판정
- URDF로 Python(numpy)에서 독립 계산한 정역학 토크 18건 + 허리 기울임 2건과 비교(오차 ~1e-9 N·m)
- 질량행렬 대칭·RNEA 선형성, 자유진동 에너지 보존, 궤적 속도·가속도 제한
- 팔 뻗은 자세 0/1 kg Δτ = 이론(하중 중력모멘트를 실제 관절축에 투영), 정적 추종오차, 팔 질량 ×1.5 → 토크 ×1.5
- 과부하(20 kg @ 0.2 m)에서 발산·떨림 없음
- 충돌: 몸 안쪽 목표 4개에서 최대 침투 < 5 mm (충돌을 끄면 같은 목표에서 75 mm 뚫림)
- 구동부: 정지 토크 불변, 등속 구간에서 (구동토크 − 출력축 토크) = 마찰
- 랜덤 자세 12개: 조건 만족·도달 오차 < 0.1°·포화/접촉 없음
- 임피던스(마찰 0): 무외력 유지 < 1 mm, 20 N 일정 외력에 변위 = F/K (24.3 vs 25.0 mm), 제거 후 복귀
- 충격 150 N·30 ms: 두 방식 모두 발산 없이 복귀, 10 N 지속 외력 변위 위치 6.4 mm / 임피던스 31 mm

## 관절 감속기 실시간 판정 (`reducer.html`, 별도 페이지)
기본 시뮬레이터(index.html · app.js)를 그대로 띄우고, 그 위에 관절별 유성감속기 판정을 실시간으로 겹친다.
3D·슬라이더·충격·랜덤 자세·임피던스·하중 등 기존 기능은 모두 같고, 매 1 ms 스텝마다 아래를 계산한다.
- `reducer_core.js` `Live` (sim.step을 감싸 매 스텝 tick, 브라우저·Node 공용)
  - 관절 반력: 뉴턴–오일러(충격 외력 포함, 몸 접촉력 제외) → 관절축 기준 Fa·Fr·M
  - 관절별 2관성 유연 모델: 모터 Jm – 비틀림 강성 K + 백래시 ±δ – 링크 Jl(다른 관절 잠금 유효관성, 10 ms마다 갱신).
    링크 하중 = 강체 출력축 토크 − Jl·q̈, 모터 = 강체 구동 토크 피드포워드 + PD(토크 한계 URDF effort), 고유진동수에 맞춰 1 ms를 잘게 나눠 적분
  - 판정: 기어 = 설계실 엔진 정적 강도(ISO 6336)를 토크별 표로 미리 계산해 로그 보간, 유성 베어링 = 핀 하중/C0, 출력 베어링 = C0/P0,
    P0 = Fr + 2000·M/dp + 0.44·Fa
- 화면: 관절마다 유성감속기 기어세트 3D(`reducer_gears.js`, 설계실 viewer3d의 치형·배치·위상 그대로, 실제 크기·실제 감속비로 회전,
  링 = 부모 링크 고정 · 마지막 캐리어 = 관절 출력). 색 = 부품별 여유(썬·유성·링 = 기어 접촉·굽힘, 캐리어 원판 = 그 단 유성 베어링,
  바깥 고리 = 출력 베어링), 0.5 s 최저값 유지. 로봇 외피 반투명·확대 배율 선택.
  관절별 현재·최저 여유 표, 최근 3 s 강체 vs 기어 토크 그래프(이 떨어짐 눈금)
- 감속비·기어 제원 선정: 대상 관절의 피크 토크를 요구 토크로 가져와 설계실 추천 엔진(`vendor/pgd/recommend.js`)으로
  잇수·모듈·치폭·유성 수 조합을 찾고(외경·길이·감속비 편차·구성 조건), 정적 한계 토크가 요구 이상인 것부터 보여줌 → [추가]로 새 종류(D1…) 배치.
  종류별 잇수·모듈·치폭·유성 수·비틀림각 직접 수정(엔진 판정 오류가 있으면 적용 안 함)
- [적용] 시 구동부 표 J를 감속기 Jm으로 맞춰 강체 계산과 유연 모델의 모터 관성을 일치시킴
- `app.js` 변경은 점검용 객체 `window.__h2x`에 scene · linkGroups · model 읽기 전용 접근자 추가뿐 (기본 시뮬레이터 동작 불변)
- 감속기 계산 엔진: `vendor/pgd/` = [PLANETARY-GEAR](https://github.com/pso1021835-eng/PLANETARY-GEAR) @ `26b4b50` 의 `engine.js`, `carrier-geometry.js`, `viewer3d.js`, `recommend.js`, `bearings.js` 복사본
- 감속기 예시 제원 A·B·C (`reducer_presets.js`): 설계실 추천 엔진(recommend.js runSync)으로 자동 생성
  (A Ø80×42 i≈22.5 · B Ø66×36 i≈20 · C Ø52×30 i≈16). **H2-X 실물 제원 아님.** 화면에서 설계 JSON을 붙여 넣어 바꿀 수 있음
- 모터 쪽 반사관성 Jm 기본값: A 0.0251(unitree_rl_lab N7520-22.5), C 0.0036(N5020-16), B 0.012(공개값 없음 → 가정)
- 한계: 관절 사이 유연 연성·이빨 접촉 FEM·피로 누적 없음, 출력 베어링 하중은 강체 값(접촉력 제외). 결과는 "먼저 한계에 닿는 부품" 순위용
- 검증 `node reducer_test.js`: 마찰 0에서 반력 축 토크 = 시뮬레이터 출력축 토크(1e-9), 정지 반력 = 무게, 예시 제원 감속비·정적 한계,
  한계 토크에서 판정 여유 = 1, 백래시 0·고강성 → 강체와 같음, 백래시가 있으면 이 떨어짐 발생,
  실시간(Live) 피크 = 일괄 계산 피크(5 %), 기어 여유 표 보간 = 엔진 직접 계산(3 %)
