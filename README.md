# ROBOT-ARM-TORQUE — H2-X 오른팔 토크–각변위 (웹)

Unitree H2-X 전신이 서 있는 상태(골반 고정)에서 오른팔 7축을 슬라이더로 움직이고,
팔 자체 질량·손 하중(무게중심 오프셋 포함)을 바꾸면서 관절별 **감속기 출력축 토크–각변위**를 실시간으로 본다.
index.html을 연 화면이 곧 시뮬레이터 (GitHub Pages: main / root).

## 계산
- `dynamics.js` (외부 라이브러리 없음, 브라우저·Node 공용)
  - 링크 질량·무게중심·관성텐서 = URDF 원본. 골반 고정, 높이 1.0237 m(발바닥 z=0)
  - 역동역학 RNEA, 질량행렬 = 단위가속도 RNEA, 적분 1 ms
  - 구동: 속도·가속도 제한 궤적 → 피드포워드(실제 자세 · 기준 궤적의 역동역학 + 구동부 보상) + 관절별 PD
    (관성 스케일 D는 폐루프 고유값 λ = eig(D½M⁻¹D½) ≤ 3이 되게 축소 → 한 관절이 포화돼도 다른 관절이 떨지 않음)
  - 토크 한계 = URDF `effort` (구동 명령 클립), 가동범위 = 기계식 스토퍼(충격량)
- **구동부(액추에이터) 모델** — URDF에 없는 값이라 관절별 가정값, 화면 표에서 수정
  - 로터 반사관성 J = 로터관성 × 감속비² (기본 0.03 / 0.025×3 / 0.01×3 kg·m²)
  - 마찰 τf = b·ω + τc·tanh(ω / 0.02 rad/s) (기본 b 1/1/1/1/0.5/0.5/0.5 N·m·s/rad, τc 1/0.5/0.5/0.5/0.25/0.25/0.25 N·m)
  - 마찰은 암시적으로 적분(안정). [구동부 0] 버튼 = 강체 이상값
  - **그래프 토크 = 감속기 출력축 토크 = 구동토크 − J·q̈ − τf** (링크에 실제 전달되는 토크; 정지 시 마찰 0이면 구동토크와 같음)
- **충돌**
  - 모든 링크 메시를 k-means 구 735개로 근사(`tools/make_model.py`, 표면적 비례 개수)
  - 오른팔 7링크(+손 하중 구) ↔ 몸(몸통·골반·다리·머리·왼팔), 오른팔 자기충돌(인접 링크 제외)
  - 기준 자세에서 이미 겹치는 링크 쌍(어깨 관절부)과 몸통 구 중 오른어깨 관절 반경 13 cm 이내는 제외
  - 접촉은 비탄성 충격량(투영 가우스–자이델, 스토퍼와 함께 풂), 접촉력과 상대 링크를 화면에 표시
- **몸 자세**: 허리 yaw·roll·pitch, 머리 2축, 왼팔 7축을 슬라이더로 설정(정적 고정). 허리를 기울이면 오른팔 기준 중력 방향이 바뀜. 다리는 골반 고정이라 0 rad 표시만
- 팔 질량 변경: 7링크 질량·관성 ×k, 무게중심 유지. 손 하중: 손 링크(`right_wrist_yaw_link`)에 균질구(r 3 cm)로 강체 결합, 들 때 1초 램프 · 내려놓기 즉시

## 검증
`node dynamics_test.js` — 모두 자동 판정
- URDF로 Python(numpy)에서 독립 계산한 정역학 토크 18건 + 허리 기울임 2건과 비교(오차 ~1e-9 N·m)
- 질량행렬 대칭·RNEA 선형성, 자유진동 에너지 보존, 궤적 속도·가속도 제한
- 팔 뻗은 자세 0/1 kg Δτ = 이론(하중 중력모멘트를 실제 관절축에 투영), 정적 추종오차, 팔 질량 ×1.5 → 토크 ×1.5
- 과부하(20 kg @ 0.2 m)에서 발산·떨림 없음
- 충돌: 몸 안쪽 목표 4개에서 최대 침투 < 5 mm (충돌을 끄면 같은 목표에서 75 mm 뚫림)
- 구동부: 정지 토크 불변, 등속 구간에서 (구동토크 − 출력축 토크) = 마찰
